# Требования к приложению "Заметки с тегами"

## 1. Проблема

Пользователи часто создают заметки с разной информацией, но теряются в большом количестве записей. Отсутствие удобной системы категоризации затрудняет поиск нужной информации. Приложение решает проблему организации и быстрого поиска заметок через систему тегов.

## 2. Целевая аудитория

- Студенты и школьники для конспектов
- Фрилансеры для организации рабочих задач
- Все, кто ведет личные заметки и хочет их структурировать

## 3. Функциональные требования

1. **Добавление заметки** - создание заметки с заголовком, текстом и тегами
2. **Редактирование заметки** - изменение существующих записей
3. **Удаление заметки** - удаление ненужных записей
4. **Просмотр всех заметок** - отображение списка всех записей
5. **Фильтрация по тегам** - поиск заметок по одному или нескольким тегам
6. **Поиск по заголовку и тексту** - полнотекстовый поиск
7. **Облако тегов** - визуальное отображение всех тегов с частотой использования

### Основные маршруты:
- `GET /` - главная страница со списком заметок
- `GET /add` - страница добавления заметки
- `POST /add` - обработка формы добавления
- `GET /edit/<id>` - страница редактирования
- `POST /edit/<id>` - обработка редактирования
- `GET /delete/<id>` - удаление заметки
- `GET /?tag=<tagname>` - фильтрация по тегу

### Функции:
- `get_db()` - подключение к БД
- `process_tags()` - обработка тегов (добавление #, удаление дубликатов)
- `index()` - отображение главной страницы
- `add()` - добавление заметки
- `edit()` - редактирование заметки
- `delete()` - удаление заметки
