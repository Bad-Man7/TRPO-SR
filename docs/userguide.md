# Руководство пользователя "Заметки с тегами"

## Установка и запуск

1. Установите Python 3.7+
2. Установите зависимости:
```bash
pip install flask pytest
3. Запустите приложение:
python app.py
4. Откройте браузер и перейдите по адресу: http://127.0.0.1:5000


Использование
    Добавление заметки
        Нажмите кнопку "Добавить заметку"
        Заполните поля:
            Заголовок - краткое название заметки
            Текст заметки - основное содержание
            Теги - ключевые слова через пробел или запятую (например: "работа важное идея")
        Нажмите "Сохранить"
    Просмотр заметок
        На главной странице отображаются все заметки. Каждая заметка показывает:
            Заголовок
            Текст
            Теги (кликабельные)
            Кнопки "Редактировать" и "Удалить"
    Фильтрация по тегам
        Нажмите на любой тег в заметке, чтобы увидеть все заметки с этим тегом
        В верхней странице отображаются все доступные теги для быстрой фильтрации
        Для сброса фильтра нажмите "сбросить" или на главную страницу
    Редактирование заметки
        Нажмите "Редактировать" на нужной заметке
        Измените необходимые поля
        Нажмите "Обновить"
    Удаление заметки
        Нажмите "Удалить" на заметке
        Подтвердите удаление

Примеры использования тегов
    работа проект дедлайн - три тега
    #важное, #срочное - теги с решеткой (автоматически обработаются)
    личное - один тег
